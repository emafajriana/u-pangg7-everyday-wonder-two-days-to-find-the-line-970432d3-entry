A make.fun entry for "Everyday Wonder, Two Days to Find the Line": one sentence, at most 200 characters, that makes a small everyday moment strange and new.

## The entry

> The supermarket's automatic door opens for the pigeon every single time, and never once for me.

(95 characters — one sentence, one line.)

## How it works

`main.py` (Python 3.13, standard library only) writes the sentence to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). Before writing it enforces the competition's gate — 1 to 200 characters, not only white space, a single line — then reads the file back and verifies it byte-for-byte.

Run it:

```sh
python3 main.py
```
